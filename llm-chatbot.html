LLM Knowledge Editing Chatbot

A chatbot interface that lets users select any model from Hugging Face and apply parametric knowledge edits conversationally — no direct parameter manipulation required.

Featured image · video · GIF

Overview

This tool bridges the gap between knowledge editing research and practical usability. Parametric knowledge editing — the process of directly modifying what a language model "knows" by altering its weights — is a powerful technique, but it typically requires technical expertise and access to model internals. This project wraps that capability inside a conversational interface.

Users can select and load any model available on the Hugging Face Hub, then apply knowledge edits through natural language commands within the chat. The system interprets the intent, performs the edit on the model's parameters, and allows the user to immediately test the result through further conversation.

The project is currently under development. The goal is to make parametric knowledge editing accessible to researchers and practitioners who need to correct, update, or customize model knowledge without retraining.
