Overview

This entry covers a range of Android smartphone projects developed over the years, from small utility apps to more product-focused applications. The common thread across all of them is a focus on usability and code quality — clean architecture, responsive layouts, and interactions that feel natural on mobile.

Projects in this area have included WebView-based hybrid apps with custom JavaScript bridges, native UI-heavy applications using both XML layouts and Jetpack Compose, and apps that integrate device sensors, notifications, or background services.

Development has spanned both Kotlin and Java depending on the project context, always following current Android SDK guidelines and Material Design principles.
